# Launch Readiness Matrix

| Area | Stage 08 status | Required before public launch |
| --- | --- | --- |
| Responsive UI and core routes | Ready for stakeholder review | Real-device and assistive-technology acceptance testing |
| Menu and working prices | Structured, internally consistent | Owner approval, inventory mapping, final prices |
| Ordering and payments | Safe test mode only | PCI-hosted payment UI, merchant account, taxes, fees, refunds, POS |
| Accounts and rewards | Memory/local prototype only | Production identity, database, recovery, fraud and loyalty rules |
| Student mode | Review status only | Approved eligibility and verification process |
| Business/catering | Request-flow prototype | Quote workflow, deposits, cancellation and service terms |
| Allergens and nutrition | Honest warnings; no invented nutrition | Recipe, supplier, portion and kitchen-control verification |
| Privacy and legal | Review-ready drafts | Owner and appropriate professional approval; real vendor details |
| SEO and local search | Pre-launch metadata; indexing blocked | Domain, canonical URLs, sitemap, verified hours/contact/map profile |
| Media | Concept assets labeled | Final product and packaging photography |
| Security | Baseline headers and safe test controls | Production threat review, secrets, logs, monitoring, rate limits |

Stage 09 may begin only after the launch owner resolves or explicitly accepts every blocker relevant to the chosen release scope.
