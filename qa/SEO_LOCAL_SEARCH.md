# SEO & Local Search Handoff

The package is intentionally `noindex, nofollow` and `robots.txt` blocks crawling. This prevents a prototype with working prices, placeholder media, and incomplete public contacts from entering search results.

Before removing the block:

1. Connect the approved domain and HTTPS.
2. Add one canonical URL per crawlable route.
3. Create production Open Graph/Twitter image URLs.
4. Add a sitemap using the public origin and only indexable routes.
5. Add verified LocalBusiness/FoodEstablishment structured data: exact business name, public URL, phone, hours, address, price range, ordering URL, and same-as profiles.
6. Verify Google Business Profile and map pin ownership.
7. Add unique server-rendered metadata for menu, catering, location, and product pages.
8. Replace hash routes or add an indexing-compatible rendering strategy.
9. Connect search-console tools and monitor coverage after launch.

Do not publish structured data with guessed hours, phone numbers, reviews, ratings, prices, or opening status.
