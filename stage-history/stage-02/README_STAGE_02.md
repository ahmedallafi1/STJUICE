## Purpose

This cumulative package contains the complete Stage 01 foundation plus the approved Stage 02 visual system. It is now the single canonical starting point for Stage 03.

Stage 02 locks:

- A pistachio-led color system with accessible interface pairings.
- Fraunces + Manrope as the brand typography pair.
- The original **Saint Slice** dragon-fruit-inspired symbol.
- Horizontal, stacked and mark-only logo assets.
- Default, Student and Business/Catering theme tokens.
- Buttons, cards, badges, icon rules and the Seed Orbit pattern.
- The first packaging system and visual packaging board.
- Legal, accessibility and brand-usage guardrails.

## Authority rules

- This returned ZIP is the only accepted source for Stage 03.
- Locked Stage 01 facts remain unchanged.
- Stage 02 visual tokens are authoritative until the user explicitly requests a change.
- Competitor and university assets must not be copied.
- Student styling must not imply university affiliation or sponsorship.
- The logo asset is original concept artwork for the project; trademark clearance remains a launch dependency.
- Exact nutrition, ingredient and allergen claims remain unverified until Stage 03 data and recipes are reviewed.

## ZIP handoff protocol

At the end of every stage:

1. Preserve all approved earlier work.
2. Add the current stage work without silently changing locked decisions.
3. Update `CHANGELOG.md` and `08_STAGE_STATUS.md`.
4. Validate files, links, structured data and the ZIP archive.
5. Create the next numbered cumulative ZIP.
6. Return that ZIP for the following stage.
