## Authority rules

- The user's latest explicit instruction overrides an older assumption.
- Locked decisions must not be changed without an explicit request.
- Temporary placeholders may be improved but must remain clearly identifiable until replaced.
- Competitor systems may inspire functionality, but competitor names, copy, photographs, videos, logos and protected visual elements must not be copied.
- Student styling may be SLU-neighborhood-inspired, but must not use official SLU marks or imply university sponsorship.
- Exact nutrition claims require verified recipes, weights and ingredients before public release.

## ZIP handoff protocol

At the end of every stage:

1. Preserve all approved earlier work.
2. Add only the current stage's work and necessary corrections.
3. Update `CHANGELOG.md` and `08_STAGE_STATUS.md`.
4. Validate the package before compression.
5. Create the next numbered ZIP.
6. The user returns that ZIP for the following stage.

No stage should start from an inferred or recreated copy when the returned ZIP is available.
