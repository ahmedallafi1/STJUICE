# ST. JUICE — Asset Naming Rules

## Pattern

`{subject-or-catalog-id}-{view-or-purpose}-{status}-v{number}.{extension}`

Examples:

- `pistachio-saint-concept-v1.png`
- `st-juice-hero-1600.webp`
- `hero-loop-storyboard-concept-v1.png`
- `birthday-box-front-approved-v2.webp`

## Rules

- Lowercase kebab case only.
- Use the canonical catalog/category ID when one exists.
- Keep version numbers; do not overwrite an approved source silently.
- Use `concept` in every generated factual-image placeholder filename.
- Web derivatives may omit `concept` only when the source name remains present and the manifest explicitly inherits source status; current derivatives retain it wherever practical.
- Pixel-width suffixes are allowed for responsive images.
- Do not use `final` unless owner approval, rights, recipe/packaging truth and launch checks are recorded.
- Update both manifest files whenever an asset is added, replaced or approved.

## Suggested final-production views

- `front`
- `angle-45`
- `macro`
- `ingredients`
- `hand-scale`
- `lifestyle`
- `packaging`
- `bundle`
- `vertical`
- `horizontal`

Example: `pistachio-saint-angle-45-approved-v1.webp`.
