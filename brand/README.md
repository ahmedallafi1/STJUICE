# Brand folder

This folder is the working visual system for ST. JUICE.

Open `brand-board.html` for the quickest visual review. Developers should begin with `tokens/st-juice.tokens.json` and `tokens/st-juice.css`. Production teams should use the logo SVGs in `assets/logos/`, not recreate the mark from screenshots.

The packaging board is a style reference, not a manufacturing dieline. Final dimensions, substrate, ink, food-contact compliance and printer tolerances must be confirmed with vendors.
